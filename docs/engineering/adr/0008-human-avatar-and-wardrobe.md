# Continuous human avatar and procedural wardrobe

DEC-27 / DEC-28, 2 November 2026. REQ-028, REQ-029 / TC-032, TC-033. The owner accepted MetaHuman realism as a core experiment, then requested limp arms, military clothing variation and the same avatar before and after death.

Use one assembled optimized medium MetaHuman with 2K textures for this POC. Creator/source authoring stays editor-only. Runtime consumes cooked skeletal meshes, physics, facial RigLogic and generated fitted garments. Identity variety beyond this source character is deferred; facial tension and uniform palettes are seeded now. No claim of a finished character art set follows from this experiment.

`MSHumanAppearance` owns mesh assembly, material selection and facial presentation. Pure `AvatarRules` owns deterministic uniform selection. CharacterMovement and the capsule own movement and stance. `MSBodyAnim` provides initial procedural locomotion and crouch poses. On death, game orchestration passes the live mesh to the ragdoll adapter, which snapshots its evaluated local pose and world mesh transform before enabling physics. Validate evaluated LOD bones; removed LOD bones have no meaningful component transform. First-person head hiding affects rendering only. The class-default mesh offset must be set in the Character constructor, because crouch restores that default.

`MSHumanRagdoll` adapts Epic's 24-shape assembled physics asset to the existing supported-settlement contract. A hanging-arm fixture exposed pose-holding drives: hands stayed near shoulder height despite joint motion. Disable dead-joint position/velocity drives. Widen shoulder swing to 80 degrees and twist to 45; retain elbow swing hinges and permit 90 degrees of elbow twist. Both arms must hang at least 45 cm below the shoulders in the pinned-torso gravity fixture and show independent shoulder/elbow motion. This is an initial gameplay profile, not anatomical production acceptance.

Generated uniforms retain the owned body's binding and receive a fitted outer shell with inherited skinning, military fabric parameters and optional vest. Garments copy the body's pose after physics and add no collision. Freeze their evaluated pose when cover commits. These are prototype fitted garments, not simulated loose fabric or a finished tactical kit. Chaos Outfit offers parametric fitting and Mutable offers richer runtime assembly; neither is enabled merely to claim feature coverage.

Render-data skin-weight extraction needs initialized rendering resources. The recipe rejects absent/root-only weights instead of silently baking a rigid shell. Run the wardrobe commandlet with `-AllowCommandletRendering -RenderOffscreen`, without `-nullrhi`, then review deformed full-body captures. Preserve recipes, seeds, source assets and cooked dependencies with Git LFS. Ground geometry is baked through Geometry Script; PCG edge gravel and enhanced direct/sky/contact lighting remain cosmetic and preserve authored collision.

Production gates remain: authored garments and boots, more identities, animation polish/foot planting, collision silhouette review, larger-count hardware budgets, saves/recovery and clean-machine validation. Do not treat this POC as release acceptance.
