# Meat Shield review templates

Copy a template into the chosen project tracker or a dated implementation-results record when it is used. Preserve task requirement test and build IDs. Empty templates are not completed reviews.

- [Milestone review](milestone-review.md) records gate evidence, scope, forecast, and decision.
- [Playtest report](playtest-report.md) separates observation, explanation, events, and interpretation.
- [Decision record](decision-record.md) captures alternatives, consequences, and affected contracts.
- [Implementation task](../.github/ISSUE_TEMPLATE/implementation_task.md) supports tracker work.
- [Bug report](../.github/ISSUE_TEMPLATE/bug_report.md) records reproducible build-specific defects.
- [Pull request](../.github/PULL_REQUEST_TEMPLATE.md) connects a change to acceptance and evidence.
